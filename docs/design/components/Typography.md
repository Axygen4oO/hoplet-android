## Назначение

Этот документ фиксирует типографическую систему Hoplet.  
Новые компоненты не могут вводить собственную текстовую шкалу вне описанных ниже стилей.

---

## Базовый принцип

Hoplet использует нейтральный читаемый grotesk, зафиксированный в исходном стандарте как `Inter` или визуально эквивалентный.  
Типографика должна быть собранной, плотной и инструментальной, а не медийной или декоративной.

---

## Шкала

| Стиль | Размер / межстрочный | Вес | Основное применение |
| --- | --- | --- | --- |
| `Display` | `40 / 46` | Bold | редкие hero-акценты и большие статусные числа |
| `Headline` | `28 / 34` | SemiBold | крупные экранные заголовки |
| `Title` | `20 / 26` | SemiBold | заголовки карточек и bar title |
| `Body` | `16 / 24` | Regular | основной читаемый текст |
| `Body Dense` | `14 / 20` | Regular | settings rows, компактные описания |
| `Label` | `13 / 18` | Medium | кнопки, теги, короткие метки |
| `Caption` | `12 / 16` | Regular | подписи и пояснения |
| `Status` | `12 / 16` | SemiBold | inline-status, chips, counters |

---

## Правила применения

- Длинные текстовые блоки писать в `Body`, не мельче.
- На одном экране обычно достаточно одного headline-level, одного title-level, одного body-level и одного caption-level.
- IP, порт, тайминг и другие технические значения должны быть легко сравнимы; при необходимости использовать tabular digits.
- All caps допустимы только для очень коротких служебных меток.
- Нельзя строить внутри одной карточки лестницу из множества случайных размеров.

---

## Где какой стиль использовать

| Контекст | Рекомендуемый стиль |
| --- | --- |
| Screen title | `Headline` или `Title` |
| Card title | `Title` |
| Main body copy | `Body` |
| Dense row text | `Body Dense` |
| Button label | `Label` |
| Helper text | `Caption` |
| Status / chip / counter | `Status` |
| Large metric | `Display` или акцентный `Headline` |

---

## Ограничения

- Нельзя уменьшать long-form текст до `Caption`, чтобы "уместить больше".
- Нельзя вводить отдельные экраны со своей собственной шкалой типографики.
- Нельзя использовать декоративные контрасты веса там, где хватает нормальной иерархии.

---

## Проверка перед использованием

1. Ясно ли, какой текст на экране главный?
2. Нет ли внутри компонента более двух-трех уровней текста?
3. Легко ли сравнивать цифры и технические значения?
4. Не пришлось ли уменьшить текст ради эффекта или плотности?
