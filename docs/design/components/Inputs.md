## Группа

Поля ввода в Hoplet твердые, читаемые и предсказуемые.  
Glass не является базовым материалом форм.

---

### TextField

**Назначение**  
Стандартный однострочный ввод текста, чисел или коротких параметров.

**Где используется**  
Экран формы, настройки, диалоги, bottom sheets с коротким вводом.

**Когда использовать**  
Когда пользователю нужно ввести одно значение вручную.

**Когда НЕ использовать**  
На сложном фоне, внутри glass-on-glass слоя или для выбора из конечного списка.

**Внешний вид**  
Материал: `Surface Solid`.  
Высота: `56 dp`.  
Радиус: `18 dp`.  
Padding: `16 dp` по горизонтали.  
Типографика: `Body`.  
Placeholder: `Text Tertiary`.  
Граница: `Border Subtle`; в фокусе акцентный контур `2 dp`.

**Состояния**  
Normal, Focused, Error, Disabled, Success при явной валидации, Loading обычно не применяется.

**Поведение**  
Label читается всегда. Ошибка показывается под полем. Изменение состояния не должно сдвигать соседние элементы скачком.

**Accessibility**  
Label обязателен. Ошибка дублируется текстом. Контраст placeholder не должен мешать чтению введенного значения.

**Что разрешено изменять**  
Тип клавиатуры, label, placeholder, leading/trailing icon.

**Что запрещено изменять**  
Прозрачный фон на сложном фоне, яркая заливка в normal-state, слишком тонкая граница.

**Примеры использования**  
IP-адрес, порт, URL, имя профиля.

### PasswordField

**Назначение**  
Ввод секретного значения с контролируемым показом/скрытием.

**Где используется**  
Настройки, экраны авторизации, секции секретов, диалоги подтверждения.

**Когда использовать**  
Когда значение нужно скрывать по умолчанию.

**Когда НЕ использовать**  
Для обычного текста и технических значений, которые пользователь должен свободно сверять.

**Внешний вид**  
Наследует `TextField`.  
Trailing icon является secondary-action.  
Target иконки показа не меньше `48 dp`.

**Состояния**  
Normal, Focused, Error, Disabled, Success при явной проверке.

**Поведение**  
Показ/скрытие не меняет layout. Смена видимости не должна ломать фокус и ввод.

**Accessibility**  
У action показа пароля должна быть понятная подпись состояния: показать или скрыть.

**Что разрешено изменять**  
Label, helper-text, иконку visibility.

**Что запрещено изменять**  
Превращать поле в декоративный secure-block, уменьшать tap-target иконки.

**Примеры использования**  
Пароль, PIN, секретный ключ, passphrase.

### SearchField

**Назначение**  
Локальный поиск по списку, секции или набору элементов.

**Где используется**  
Экран списка, поиск по исключениям, поиск по профилям, фильтры.

**Когда использовать**  
Когда поиск относится к одному экрану или одному набору данных.

**Когда НЕ использовать**  
Как глобальный бренд-элемент или вместо полноценной навигационной search-shell.

**Внешний вид**  
Материал: `Glass` только для короткой верхней строки; иначе `Surface Soft`.  
Иконка поиска слева, очистка справа.  
Типографика и радиус наследуются из общей системы поля.

**Состояния**  
Normal, Focused, Disabled, Loading при асинхронной фильтрации, Error обычно не применяется.

**Поведение**  
Фильтрация должна быть предсказуемой. Поле не должно визуально доминировать над результатами.

**Accessibility**  
Нужна словесная подсказка о том, что именно ищется: профили, приложения, серверы.

**Что разрешено изменять**  
Placeholder, иконку очистки, локальный material choice между glass и soft surface.

**Что запрещено изменять**  
Использовать glass внутри плотной фильтровой формы, делать search-field полностью прозрачным.

**Примеры использования**  
Поиск приложений, поиск профилей, фильтрация серверов.

---

### DropdownField

**Назначение**  
Выбор одного значения из конечного списка с визуальным языком обычного поля.

**Где используется**  
Настройки, формы, ролевой выбор, выбор режима или DNS-профиля.

**Когда использовать**  
Когда значений несколько, но они фиксированы и не требуют отдельного экрана выбора.

**Когда НЕ использовать**  
Для бинарного переключения или длинного сложного списка без структуры.

**Внешний вид**  
Визуально совпадает с `TextField`.  
Справа используется chevron.  
Раскрывающееся меню наследует `Popup` или `Surface`.

**Состояния**  
Normal, Focused, Disabled, Error.

**Поведение**  
Открывается из того же визуального языка. Текущий выбор всегда видим без дополнительного раскрытия.

**Accessibility**  
Нужно объявлять текущее значение и факт раскрытия списка. Chevron не заменяет label.

**Что разрешено изменять**  
Список значений, текущее value-label, helper-text.

**Что запрещено изменять**  
Делать меню стилистически отдельным от Popup/Surface языка Hoplet.

**Примеры использования**  
Выбор роли, режима, типа резолвера, готового пресета.
